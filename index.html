DISCOVERY 01 / 05 · SKYPIEACapstone project

GateOrchestra

A lightweight, trainable gate that sits in front of a multi-agent orchestrator. Using only pre-execution signals, it decides whether a cheap single-agent probe answer is good enough or whether the full multi-agent system is worth its tokens. Built with a four-person team.

  • 33% fewer tokens than always running the multi-agent system, at higher accuracy (97.9% vs 92.2% on Qwen2.5-3B)
  • Evaluated on 96 held-out tasks across two seeds, under equal token budgets
PythonMulti-Agent SystemsCoT-SCQwen2.5 / GroqReact
GitHub ↗
DISCOVERY 02 / 05 · SKYPIEA

Autonomous Orchestrator Agent

An audited multi-agent orchestration service. Plain-language instructions are routed across a nine-agent roster, with a human approval gate in front of anything outbound, a crash-resilient autonomy engine, sandboxed web browsing and multi-tier memory.

  • HMAC-signed human-in-the-loop approval gate that cannot be bypassed
  • 239 passing tests and a 100% score on the router evaluation harness
PythonFastAPISQLiteChromaDBReact 18SSE
GitHub ↗
DISCOVERY 03 / 05 · SKYPIEA

Self-Improving Code Agent

A sandboxed, self-repairing coding agent. It runs untrusted Python inside isolated Docker containers, reads its own tracebacks to repair bugs, remembers failure patterns in ChromaDB vector memory, and audits the result through multi-agent review.

  • Spec tests are written first; every step streams live over server-sent events
  • Verified runs earn a certificate: tests, coverage, security findings and complexity
PythonFastAPIReact 19DockerGroqChromaDB
GitHub ↗
DISCOVERY 04 / 05 · SKYPIEA

NebulaLM

A decoder-only language model for space and astronomy, built from scratch, and a pre-registered study of what a 4.5M–29M parameter model learns, stores and leaks as it trains on repeated text.

  • The 29.4M model reaches 1.060 bits per byte on the sealed test split — 23% below a 5-gram baseline
  • Verbatim extraction stays under 1%; rejected hypotheses are reported as rejected
PythonPyTorchTransformer from scratchBPE TokenizerMemorization Audits
GitHub ↗
DISCOVERY 05 / 05 · SKYPIEAInternal SIH 2026 · 1st place

Visentra

A forensic workstation for computer-vision supply chains. It ties cryptographic provenance — hashes, Merkle roots and Ed25519 signatures — to behavioural checks on one live lineage graph, so a poisoned sample, a flipped weight bit or a planted backdoor all surface in the same place.

  • Four pillars: dataset integrity, model integrity, backdoor screening and inference binding
  • Every prediction downstream of a tampered artefact loses its certificate
PythonFastAPIComputer VisionEd25519 / MerkleReact 19Three.js
GitHub ↗
